# NEXO

Мобильный мессенджер на React Native (Expo SDK 58) с собственным сервером на Supabase. Текст личных сообщений шифруется на телефоне до отправки, на сервере хранится только шифротекст.

## Что работает в версии 1.0.0

| Сессия в защищённом хранилище (Keystore / Keychain) | ✅ |

## Шифрование: что есть и чего нет

Есть:
- Пара ключей X25519 создаётся на устройстве. Секретный ключ хранится в `expo-secure-store` (Android Keystore / iOS Keychain) и никогда не уходит на сервер.
- Каждое сообщение шифруется `crypto_box` (X25519 + XSalsa20-Poly1305, библиотека TweetNaCl) с новым случайным nonce. В базе лежат только `ciphertext`, `nonce` и публичные ключи.
- Подделанное или повреждённое сообщение не расшифровывается.
- «Код безопасности»: собеседники могут сравнить его при встрече и убедиться, что сервер не подменил ключ.

Нет (поэтому мы **не** называем это полноценным E2EE уровня Signal):
- Прямой секретности (forward secrecy): используется статический ключ, а не Double Ratchet.
- Нескольких устройств: вход с нового телефона создаёт новый ключ, и старую переписку там не прочитать. После переустановки приложения тоже.
- Шифрования групп и вложений, потому что сами эти функции ещё не сделаны.

Сервер видит метаданные: кто с кем переписывается, когда и какого размера сообщения.

## Безопасность сервера

Схема и политики находятся в `supabase/migrations/0001_init.sql`:
- RLS включён на всех таблицах. Сообщения и участников чата видят только участники этого чата.
- Чаты и участники создаются только серверными функциями (`create_direct_chat`), прямая запись запрещена.
- Отправитель подставляется сервером, подделать его нельзя. Чужие сообщения и профили менять нельзя.
- Блокировка проверяется на сервере и запрещает переписку в обе стороны.
- Ограничение частоты: не больше 20 сообщений за 10 секунд от одного пользователя.
- Анонимный (не вошедший) клиент не читает ни одной таблицы.
- Удаление аккаунта (`delete_my_account`) удаляет пользователя и все его данные.
- В приложении используется только публичный ключ `anon`. Экран настройки отказывается принимать ключ `service_role`.

## Тесты

```bash
npm test          # 13 тестов шифрования: чужой не расшифрует, подмена и порча обнаруживаются, неверный ключ отклоняется
npm run lint      # проверка типов TypeScript
```

`supabase/tests/rls_test.sql` — 17 проверок прав доступа к базе (посторонний не читает и не пишет в чужой чат, подделка отправителя, блокировка, rate limit, аноним, удаление аккаунта). Запуск — на базе с применённой миграцией:

```bash
psql "$DATABASE_URL" -f supabase/tests/rls_test.sql
```

## Настройка сервера (можно целиком с телефона, через браузер)

1. Зарегистрируйтесь на https://supabase.com и создайте проект (бесплатный тариф подходит).
2. Откройте **SQL Editor → New query**, вставьте всё содержимое `supabase/migrations/0001_init.sql` и нажмите **Run**.
3. **Authentication → URL Configuration → Redirect URLs**: добавьте `nexo://**` (нужно для ссылок подтверждения email и сброса пароля).
4. **Project Settings → API**: скопируйте **Project URL** и публичный ключ **anon / publishable**.
5. Установите APK, откройте NEXO и вставьте эти два значения на экране «Подключение к серверу».

Чтобы зашить сервер в сборку и не показывать этот экран пользователям, задайте переменные из `.env.example` перед сборкой.

## Сборка

```bash
npm install
npx expo start                 # разработка (Expo Go не подойдёт из-за нативных модулей — нужен dev build)
eas build -p android --profile preview      # APK для установки
eas build -p android --profile production   # AAB для Google Play
eas build -p ios --profile production       # для App Store (нужен Apple Developer, $99/год)
```

Локальная сборка без EAS: `npx expo prebuild -p android`, затем `cd android && ./gradlew assembleRelease`. Перед этим подключите свой keystore в `android/app/build.gradle`.

iOS: bundle id `com.nexo.messenger`, `usesNonExemptEncryption: true` (приложение использует шифрование, при публикации в App Store нужно заполнить экспортную декларацию). Все зависимости совместимы с iOS, но iOS-сборка не проверялась: для неё нужен аккаунт Apple.

## Структура

```
src/app/            экраны (Expo Router): setup, (auth), (app)/(tabs), chat/[id], user/[id], …
src/components/     общие компоненты интерфейса
src/contexts/       авторизация и тема
src/crypto/         box.ts — шифрование (чистые функции, покрыты тестами), keys.ts — хранение ключа
src/lib/            клиент Supabase, защищённое хранилище сессии
src/services/       чаты, сообщения, пользователи
src/types, utils, constants
supabase/migrations SQL-схема, RLS, серверные функции
supabase/tests      тесты прав доступа
tests/              тесты шифрования
```
